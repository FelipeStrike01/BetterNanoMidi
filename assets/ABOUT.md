# Better NanoMidi

### More music, less friction.

Better NanoMidi is an independent fork of **nanoMIDIPlayer**, reworked to make MIDI playback and music discovery more comfortable. It keeps the original goal—playing MIDI scores through a virtual keyboard or a MIDI output device—and gives it a new PySide6 + Qt Quick interface.

## What Better NanoMidi brings

- **MIDI Player** for playing score files through keyboard input or a selected MIDI output.
- **Drums Player** and **MIDI to QWERTY** tools for other ways to use MIDI.
- A refreshed interface with theme-aware branding and layouts that adapt to smaller windows.
- Playback controls for sustain, velocity, pitch, speed, keyboard range, and configurable hotkeys.
- A broader **MIDI Hub** search: when the local catalog has no match, Better NanoMidi also searches BitMidi.
- Ongoing work on faster loading, reliability, and playback quality.

The project is designed for Windows, macOS, and Linux. Features can vary with the operating system and available MIDI devices.
