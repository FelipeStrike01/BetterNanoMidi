# Better NanoMidi

### Mais música, menos complicação.

O Better NanoMidi é uma versão independente do **nanoMIDIPlayer**, aprimorada para facilitar a reprodução de MIDI e a descoberta de músicas. Ele mantém o objetivo original — tocar partituras MIDI pelo teclado virtual ou por um dispositivo de saída MIDI — e apresenta uma nova interface feita com PySide6 e Qt Quick.

## O que o Better NanoMidi oferece

- **Player MIDI** para reproduzir partituras pelo teclado ou por uma saída MIDI selecionada.
- Ferramentas de **Player de bateria** e **MIDI para QWERTY**.
- Interface renovada, com identidade visual adaptável e layouts que se ajustam a janelas menores.
- Controles de sustain, velocity, afinação, velocidade, extensão do teclado e atalhos configuráveis.
- Busca ampliada no **Catálogo MIDI**: quando não há resultados no catálogo local, o Better NanoMidi também pesquisa no BitMidi.
- Melhorias contínuas no carregamento, na confiabilidade e na qualidade da reprodução.

O projeto foi pensado para Windows, macOS e Linux. Alguns recursos dependem do sistema operacional e dos dispositivos MIDI disponíveis.
