# Better NanoMidi — logo kit

## Files

- logo-horizontal-on-dark.svg / .png: light wordmark and event bars for dark surfaces.
- logo-horizontal-on-light.svg / .png: dark wordmark and event bars for white or light surfaces.
- logo-stacked-on-dark.svg / .png and logo-stacked-on-light.svg / .png: compact stacked lockups.
- symbol-on-dark.svg / .png and symbol-on-light.svg / .png: transparent symbol variants.
- symbol-black.svg and symbol-white.svg: one-colour print and interface variants.
- app-icon-dark.svg / .png and app-icon-light.svg / .png: square desktop icons.
- BetterNanoMidi.ico: Windows icon with 16, 32, 48, 64, 128 and 256 px entries.
- preview-dark.png and preview-light.png: lockups shown on their intended surfaces.

| Light-surface ink | #27231F |
| Light-surface terracotta | #9D5338 |
| Light icon tile | #F4F1EC |

The terracotta middle bar is the active MIDI event. Keep the full mark in one colour when colour printing is unavailable.

## Use

- Keep the symbol and wordmark proportions intact; scale them together.
- Use the dark lockup on dark surfaces and the light lockup on white or pale surfaces.
- Keep clear space around the mark at least the height of one event bar.
- Use the symbol alone for a compact app tile or avatar.
- The outlined wordmark uses the bundled Inter font; it does not require Inter installed on the viewer's device.
- These files are original design concepts, not a trademark clearance. Search for similar registered marks before a public launch.
