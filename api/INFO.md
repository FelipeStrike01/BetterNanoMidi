# Better NanoMidi

Better NanoMidi is an independent fork of [nanoMIDIPlayer](https://github.com/NotHammer043/nanoMIDIPlayer), created to improve MIDI playback, music discovery, and the desktop experience.

The project keeps the original MIDI engine and adds a PySide6 and Qt Quick interface, a local MIDI library, expanded MIDI Hub search, and optional Discord Rich Presence.

## Credits

The original nanoMIDIPlayer was created by **NotHammer043 (NotHammer)** with contributions from its community. Better NanoMidi is an independent project and is not an official release of the original.
